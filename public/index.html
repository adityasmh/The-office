Budget — real numbers

There are no per-agent quotas any more: nobody is refused work for a spend cap. What actually limits work is the provider — OpenCode Go's windows, the DeepSeek credit balance, and the Claude subscription. Numbers below are read from the provider or measured from real calls; anything we cannot measure says not measured instead of a number.
Where these numbers come from. OpenCode Go windows: the Go quota endpoint, with the key this company already holds (src/company/usage.ts). DeepSeek: GET /user/balance with DEEPSEEK_API_KEY (never printed or returned) plus the off-peak clock (src/company/offpeak.ts). Claude: jcode usage --json --no-update; it is a subscription, so there is no dollar budget. Spend: the per-call cost already recorded in company/projects/*/cost.jsonl, with per-agent attribution from company/budgets.json. Read it as: provider limit = what stops work, measured spend = what was actually recorded, “spent so far” = a read-only record per agent, not a limit.
