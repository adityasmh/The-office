## Safety properties implemented
- `FLEET_GITHUB` off by default; `FLEET_GITHUB_DRY_RUN=1` (or the feature being off)
  turns every action into a "would do" log line and runs nothing.
- `commitOwned` stages ONLY the listed paths (`git add -- <paths>`), never `git add -A`
  and never `git add .`; refuses on `main`/`master` (even in dry-run).
- `push` uses no force flag, ever.
- `openDraftPr` / `readChecks` run only when not dry-run AND a token is passed in;
  otherwise they log and return without any network call.
- The token is never logged; every log line passes through `redactForLog`, and the
  harness asserts a token-shaped value never appears in captured log output.
