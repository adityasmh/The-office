## What to build (read only the "Safety rules" and "GH-1" parts of `docs/GITHUB_INTEGRATION_SPEC.md` first)
In `src/company/github.ts` export:
- `ghConfig()` returns `{enabled, dryRun}` from env `FLEET_GITHUB` (default off) and `FLEET_GITHUB_DRY_RUN`.
- `ensureRepo(dir)` throws a clear error if `dir` is not a git repo with a remote.
- `branchFor(orderId, workOrderId)` returns `fleet/<orderId>/<workOrderId>` (sanitised, no spaces).
- `commitOwned(dir, owns, message)` stages ONLY the listed paths (never `git add -A`, never `git add .`) and commits. Refuses to run on `main` or `master`.
- `push(dir, branch)` pushes with no force flag, ever.
- `openDraftPr({repo, branch, title, body, token})` calls the GitHub REST API with `fetch`; returns the PR url. Only runs when not dry-run and a token is passed in.
- `readChecks({repo, ref, token})` returns an array of `{name, conclusion}` from the REST API; same guard.
- Every function logs what it WOULD do and does nothing when dry-run is on. The token is never logged; redact anything shaped like a token in all log lines.

## Proof: `ops/github-check.ts`
