Find out where your AI spend actually goes

Send the usage export you already have. Get back a plain report computed from your own numbers, not from a sales estimate.

The problem

Most teams now pay for models, agents and coding tools. The bill arrives as one line with no owner. The useful questions are simple, and usually unanswered: which feature costs the most, which day went strange, and which calls repeat because something is retrying in a loop.

What you get

One report, built only from the export you send:

  • Where the money goes. Spend by model, by day, and by the project or key tag your export already carries.
  • Spikes. The days and hours that break the pattern, with the rows behind them so you can see what happened.
  • Possible retry loops. Near-identical calls repeated in a short window, listed with the time gaps between them.
  • Context bloat. Requests whose input is large next to the useful output, ranked by what those tokens cost you.
  • A model comparison table you can check. What the same token counts would have cost on other models, with the price list used shown beside it, so you can correct any figure you disagree with.
  • What to test before switching. The changes worth a measured trial, in order of expected effect on your bill.

How it works

  1. Export the CSV from your provider dashboard. OpenAI, Anthropic and most gateways and proxies have a usage or billing export. Keep the raw file as it came out.
  2. Send it. Write to {{CONTACT_EMAIL}} with the file attached, and say what you want to understand about the spend.
  3. Receive the report. Usually within a week, with a short call to walk through it if you want one.

What this does not do

  • It does not promise savings. It shows what your data shows, and the decision stays yours.
  • It does not touch your accounts, keys or dashboards. Nothing is connected, nothing is logged into.
  • It does not read your prompts. The analysis runs on the export file you send, not on your code or your prompt library.
  • It does not guess your workload. Where a figure in the export is unclear, the report says so instead of filling the gap.

Questions

Who is this for?

Small teams and solo builders already paying for models or agent tools, where the bill has no clear owner. If your monthly spend is a rounding error, this is not worth your money yet, and the report will not pretend otherwise.

Which export do you need?

The usage or billing CSV your dashboard can download. If you cannot find it, say so and you will get back the exact steps for your provider.

Do you need my API keys?

No. Never send keys to anyone for an audit. If a vendor asks for keys to analyse your bill, walk away.

How long does it take?

A few working days, usually within a week of the file arriving.

What happens to the file?

The handling promise is stated in the steps above. Ask for it in writing, and an NDA if you need one, before you send anything.

Can you implement the fixes too?

The report lists what to test. Implementing the changes is a separate conversation if you want it. The audit stands on its own either way.
